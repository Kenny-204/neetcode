Problem statement

You are given an array of values (numbers or strings).
Write a function that returns the number of unique values in the array.

Example
Input:  [1, 2, 2, 3, 4, 4, 4]
Output: 4


Another example:

Input:  ["a", "b", "a", "c"]
Output: 3

Constraints

The array can be empty

Values are primitive types (numbers or strings)

Do not use built-in helpers like Set
